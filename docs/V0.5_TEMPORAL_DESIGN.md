# V0.5 Temporal Video Design

## Problem in V0.4.6

V0.4.6 supplies zero motion vectors and resets Feature 18 on every source frame. That avoids invalid temporal history, but the neural reconstruction is independent frame-to-frame and can shimmer/flicker.

## V0.5.0 pipeline

1. FFmpeg decodes RGBA.
2. Optional Depth Anything V2 generates depth.
3. DIS optical-flow helper downsamples the current frame, computes current->previous flow, confidence, and scene-cut score.
4. Flow is upscaled to source resolution in pixel units.
5. Optional depth history is warped by the flow and blended only when depth difference and flow confidence are acceptable.
6. DLSSNR Feature 18 receives Color + Depth + `R16G16_FLOAT` MVec. `Reset=false` on continuous frames and `Reset=true` for the first frame / cuts.
7. Optional DLSS output history is motion-warped and lightly blended in photometrically stable regions.
8. FFmpeg encodes the stabilized result.

## Why DIS first

The V0.5 phase-1 goal is to validate Feature 18 motion-vector direction/scale and temporal history behavior before adding a native NVIDIA Optical Flow backend. OpenCV DIS is mature, dense, fast enough at reduced analysis resolution, and gives a clean A/B reference.

## Motion-vector convention

The helper explicitly calls OpenCV as `calc(current, previous)`, so the returned vector maps a current pixel to the previous-frame sample location. The values are converted from reduced-analysis pixel units to full-resolution pixel units before upload.

`MV Scale X/Y` remain user-visible because Feature 18 is an experimental interface. Default is 1.0/1.0. Negative values can be used to test sign convention without rebuilding.

## Scene cuts

Scene-cut score combines a 32-bin grayscale histogram L1 difference and mean absolute luma difference. On a cut, the flow is discarded and Feature 18 history is reset.

## Stabilizers

Depth stabilization and output stabilization are both motion compensated and confidence gated. They intentionally reject large differences to avoid turning temporal stability into obvious ghosting.

## Future V0.5.x work

- NVIDIA Optical Flow API backend (`nvofapi64.dll`) to remove Python/OpenCV CPU overhead.
- Motion-vector debug preview / heatmap.
- Automated MV sign/scale calibration clip.
- Occlusion mask from forward/backward flow consistency.
- Better scene-cut detector for flashes/fades.
- GPU-side motion/depth/output warp to avoid CPU copies.
