# V0.5.0 Temporal Test Plan

Use short 5-15 second clips first.

## A/B baseline

Render the same clip twice:

- A: Legacy - Reset Every Frame
- B: V0.5 DIS Optical Flow - Recommended

Keep every other DLSSNR and encoder setting identical.

## Test clips

1. Locked camera, detailed foliage/hair/fabric: measures neural shimmer reduction.
2. Slow camera pan: tests MV direction and scale.
3. Moving foreground object over static background: tests ghosting/occlusion.
4. Fast pan: tests flow search robustness.
5. Hard scene cut: verifies reset.
6. Auto Depth clip with moving subject: tests depth-history rejection.

## First-pass settings

- Flow Width: 320 at 1080p; 480 at 4K.
- Cut Threshold: 0.32.
- MV Scale: 1.0 / 1.0.
- Stable Output: On.
- Stable Depth: On only with Auto Depth.

## Calibration if ghosting appears

Try four sign combinations on the same short pan:

- +1 / +1
- -1 / +1
- +1 / -1
- -1 / -1

The correct convention should reduce edge trails rather than move them to the opposite side.

## Logs

Inspect `dist/video/logs/temporal-last.log`.

Expected behavior:

- Frame 1: reset=1.
- Normal consecutive frames: reset=0.
- Hard cut: scene_cut=1 and reset=1.
- Non-static shots: average MV should be non-zero.
